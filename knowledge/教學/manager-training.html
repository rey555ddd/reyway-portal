最大的誤解：把 Claude Code 當成「更聰明的 ChatGPT」。兩者根本不同。

傳統工具

一般 Claude（對話版）

  • 你問，它答，僅此而已
  • 不能操作你的電腦
  • 不能讀寫你的檔案

  • 每次都要重新介紹自己
AI Agent

Claude Code（有手有腳）

  • 可以寫程式並直接跑起來
  • 可以讀寫你電腦上的任何檔案
  • 可以搜尋網路、查資料
  • 可以幫你操作瀏覽器
  • 透過 Memory 永久記住你

重要觀念：Claude Code 不是「聊天工具」，它是可以接受派工、自主完成任務的 AI 夥伴。你說「幫我分析這份廣告數據並寫成週報」，它就真的去做完，而不是只告訴你「你可以這樣做」。

第一步：先知道目的

不是「我想用 AI 做廣告」，而是「我想讓週報從手動 4 小時變成自動 10 分鐘」。目的越清楚，輸出越精準。

最後一步：存回記憶

某個指令特別好用？存進 Memory。下次 AI 從優化版本出發，不從零開始。這就是「越用越聰明」的秘密。

笙闆心法：數字指令

展開完整數字指令說明 & 複製提示詞

打一個數字 = 啟動一整套流程。把常用動作變成肌肉記憶，效率翻倍。

指令名稱用途
0開工確認查收件夾、重載最新規則、回報進行中任務。每次新對話開頭打。
1存工作日誌決策、產出、待辦整理成 Memory。任務做完一定打。
2我這邊好了你做完你的部分，AI 接著做下一步。
3完整品質審查三視角全跑：嚴格主管 + 陌生使用者 + 功能實測。AI 自己修。

最強組合技：開工打 9（重載規則）→ 任務結束打 3 1 4（審查 + 存日誌 + 升 Skill）。三件事一行搞定。

指揮鏈 — 誰找誰說話

笙闆只跟 PM、策略、行銷說話。前端、後端、設計的工作由 PM 發包，笙闆不直接派工給他們。

這就像你不會直接叫工廠夥伴做事，你說給你的助理，助理再去協調——這樣才不會亂。

笙闆說需求 → PM 拆解派工給行銷/前端/後端 → 三人完成後回報 PM → PM 驗收，過關才整合 → PM 回報笙闆 → 結果存進 Memory

進階心法：用 AI 寫提示詞給 AI

展開詳細流程說明
  1. 開「綜合對話」——所有新任務先在這裡跟 AI 討論，把需求講清楚
  2. 請 AI 產出完整提示詞——說「請根據剛剛討論，幫我寫一個完整的提示詞，讓另一個 AI 看到就能直接動手」
  3. 開新對話貼上提示詞——新對話一啟動就精準動作，不用反覆摸索
為什麼這就是「Agent 派工 Agent」的核心

本質：綜合對話 AI = PM、新對話 AI = 執行員。老闆不直接寫 SOP 給工程師，PM 把規格寫清楚再給工程師——AI 派工同理。

PM 驗收：完整任務流程

你說需求 → 綜合對話 AI 產出完整提示詞 → PM 拆解 → 行銷/前端/後端並行 → PM 驗收 → 整合成品 → 你看 1 次說好或調一下

你的注意力是公司最稀缺的資源——派 1 個 PM、PM 驗收完才回給你，過濾掉 80% 雜訊。
Ch.4
長期記憶

Memory — 讓 AI 記住你標記已讀

Memory = AI 的長期記憶
電腦裡的 Markdown 檔案 → AI 每次啟動前讀一遍 → 不用重新說脈絡

沒有 Memory → 每次對話都要重新介紹自己。有 Memory → 每次開工 AI 自動讀取你留下的所有記錄。

沒有 Memory 的世界

  • 每次開新對話，AI 都像新夥伴
  • 你的偏好、決策、工作方式要重新解釋
  • 同樣的錯誤一犯再犯
  • 累積不了任何「公司知識」

有 Memory 的世界

  • 每次開工，AI 自動讀上次的決策記錄
  • 知道你的工作習慣與偏好
  • 記住公司的每條規則
  • 你優化的結果永久保存

Memory 的本質

就是電腦裡的 Markdown 文字檔。AI 開工前讀這些檔案，就像夥伴上班前看昨天的交接記錄。

指令技巧

如何給 AI 好的指令標記已讀

目的
我要達成什麼？越清楚越精準。
背景
現在的狀況是什麼？讓 AI 有脈絡。
限制
有哪些條件？字數、語氣、禁忌。
格式
輸出長什麼樣？條列、表格、短文。

核心原則：好的指令包含四個要素——目的（我要達成什麼）+ 背景（現在的狀況是什麼）+ 限制（有哪些條件限制）+ 格式（輸出要長什麼樣子）

壞指令 vs 好指令

廣告分析指令示範（點開看）
模糊指令

「幫我分析廣告」

「分析這份 Meta 廣告週報（CSV 附件），找出 ROAS 最差的三組受眾，每組給我一個優化建議。輸出格式：三個重點 + 各一句建議，貼給投手看的。」

文案撰寫指令示範（點開看）
模糊指令

「幫我寫文案」

好指令

「幫我寫淨淨除菌液的 IG 貼文，目標是讓第一句話就讓媽媽想停下來看。語氣輕鬆，不要用廣告腔。結尾放一個問句跟受眾互動。300字以內。」

好指令

對話太長怎麼辦？（這段最重要、會直接影響成本）

先搞懂一件事：對話越長、每次發言越貴

每次你按 Enter，AI 都要重讀整段對話歷史才能回。所以：

  • 對話累積 5 萬字，你問一句 → 收費照 5 萬+ 算
  • 對話累積 50 萬字，你問同一句 → 收費照 50 萬+ 算
  • 同一句話、後期可以是前期的 10 倍貴

真實案例：笙闆團隊 4/28～5/4 因為長對話沒及時收尾、累計燒掉 $10,958 USD（約 NT$36 萬），高峰一天 NT$11,000。這就是「拖一個對話拖太久」的代價。

重點觀念：/compact 不是省錢魔法
  • 它只是把長對話濃縮成摘要讓你後面繼續用
  • 濃縮過程本身要花一次大錢（因為要先讀完整段才能寫摘要）
  • 細節會丟（程式碼片段、檔案路徑、決策過程被壓掉）
  • 壓多次會越來越糊、AI 會「失憶」
主管鐵律

每隔一段時間，就把對話重開

不要把不相關的事黏在同一個對話裡。一個任務告一段落，就打 1 收尾、關掉、開新的。新對話會讀 Memory 接手，乾淨又便宜。

判斷時機：

  • 任務做完 → 直接 1 收尾、開新的
  • 同個對話跑超過 30～50 輪 → 考慮 /compact 續命
  • AI 開始反應變慢、答不到重點 → 立刻收尾重開、不要硬撐
  • 想到什麼就問同一個對話、把客服、文案、報表全混進去 → 最燒錢的用法
笙闆觀察：「續命」是 /compact、「重生」是新對話——能重生就不要續命。三個月後，你會發現自己一天的產出，是過去一週的量、成本還只有十分之一。

→ 一行需求：「[想要] 神隊友按一鍵能直接排程到 IG，不用手動貼」

安全使用

注意事項標記已讀

AI 是強大的工具，但它不是萬能的，也不是絕對正確的。這幾條鐵律一定要記住。

️
AI 會犯錯，而且它不會主動說「我不確定」。數字、日期、法規、人名——這類資訊一定要人工確認，不能直接使用。

絕對不給 AI 的資料

任何帳號密碼
信用卡號碼 / 銀行帳戶
夥伴身分證字號
客戶完整個資（含聯絡方式）
公司未公開財務數字
截圖出去會有問題的內容

給 AI 之前先想一下

這份資料可以讓外部人看嗎？
如果這段對話被截圖出去，有問題嗎？
AI 輸出要對外發布之前，有沒有人工確認過？
敏感決策最終要由人來拍板，不能完全靠 AI 判斷

AI 工作鐵律速查

  • 結論先說，10 秒讓老闆看懂，再說細節
  • 不說技術術語（API / deploy / commit 一律換成白話）
  • AI 能做的事全部自己做，不要反覆問老闆
  • 生成類工具必須有：一鍵範例 + 微調對話框 + 意見回報按鈕
  • 文案一律用 Claude + 行銷 Skill；圖片一律走 fal.ai
  • 任務結束前一定打「1」存工作日誌

主管的工作邊界：你要懂的 vs 丟給 AI 軍團

你要懂

主管核心 4 件

  • ▸ 四要素公式——Skill + 資料 + 任務 + 格式

  • ▸ 三標籤回報——[卡] [想要] [該死]

不用學、丟給 AI 軍團

PM 的工作 8 件

  • ▸ Agent / Skill / Memory 工程
  • ▸ MCP / API / 後端串接
  • ▸ Token 成本 / Prompt Caching
